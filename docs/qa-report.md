- 대안(결정은 담당자): ① 기본 설정으로 폼을 먼저 그리고 서버 설정은 나중에 덮기 ② Worker가 캐시된 설정으로 먼저 답하고 방문 집계는 `ctx.waitUntil`로 따로 보내기.

### 12. 보안 (권고)
- Pages 응답 헤더에는 `x-content-type-options: nosniff`와 `referrer-policy`만 있어요. HSTS, CSP, `X-Frame-Options`(또는 `frame-ancestors`)는 없어요(`web/_headers` 없음). `.dev`는 HSTS preload 도메인이라 브라우저에서는 HTTPS가 강제돼요. 클릭재킹 방지 헤더는 추가를 권해요.
- Worker
  - 허용 출처: 200이고 `ACAO: https://rfw2026.pages.dev`, `Vary: Origin`이 붙어요.
  - 다른 출처, 출처 없음, 시안(github.io) 출처: 403이에요.
  - OPTIONS: 다른 출처는 403, 허용 출처는 204예요.
  - 깨진 JSON: 400 `BAD_REQUEST`예요. GET /는 405, /health는 200이에요.
  - Origin 검사는 브라우저용 방어선이에요. curl처럼 출처를 꾸밀 수 있으니 실제 남용 방지는 IP당 횟수 제한(RL_WRITE 10회/60초)이 맡아요.
- `/admin`은 Apps Script로 302 이동한 뒤 Google 로그인 화면으로 가요. 로그인 없이는 관리자 화면에 들어갈 수 없어요.
- `worker/ npm test`: 29개 모두 통과했어요.

### 13. 서버 테스트 스크립트 (❌)
```
$ node tools/test-gas.mjs
# config
ReferenceError: location is not defined   (web/js/config.js:10, tools/test-gas.mjs:300)
```
- 커밋 `1f2febb`에서 `web/js/config.js`가 `location.hostname`을 읽게 바뀌었어요. 그런데 테스트의 vm 컨텍스트(`tools/test-gas.mjs` 299행 `{ window: {} }`)에는 `location`이 없어요. 그래서 공통 유틸, setup, 비밀키 단계까지만 실행되고 그 뒤는 실행되지 않아요.
